## 🔧 الوحدات التفصيلية

### 1. Core Modules (JSX)

#### Config.jsx
- **الغرض:** تخزين جميع الثوابت والإعدادات
- **المحتوى:**
  - `ANCHORS`: نسب نقاط الارتكاز (1-9)
  - `AE`: أسماء خصائص After Effects
  - `EFFECTS`: أسماء التأثيرات المستخدمة
  - `CACHE`: إعدادات التخزين المؤقت

#### Utils.jsx
- **الغرض:** دوال مساعدة عامة
- **الدوال الرئيسية:**
  - `apiResponse()`: تغليف النتائج كـ JSON
  - `isComp()`, `isLayer()`: فحص الأنواع
  - `escapeName()`: تهريب الأسماء للتعبيرات
  - `generateId()`: توليد معرفات فريدة

#### Cache.jsx
- **الغرض:** تحسين الأداء بالتخزين المؤقت
- **الميزات:**
  - تخزين مؤقت مع انتهاء صلاحية (1000ms)
  - `get()`, `set()`, `clear()`, `remove()`

#### Matrix.jsx
- **الغرض:** عمليات المصفوفات للتحويلات 3D
- **الدوال:**
  - `multiply()`: ضرب مصفوفتين
  - `transform()`: تحويل متجه
  - `rotation()`: إنشاء مصفوفة دوران

### 2. Detection Modules (JSX)

#### Detector.jsx
- **الغرض:** كشف حالة الطبقات وعلاقاتها
- **الدوال:**
  - `isHunter()`: هل الطبقة Hunter؟
  - `isPrey()`: هل الطبقة Prey؟
  - `getState()`: الحالة الكاملة
  - `detectCycle()`: كشف الحلقات الدائرية
  - `findAttachedLayers()`: إيجاد الطبقات المرتبطة

#### Validator.jsx
- **الغرض:** التحقق من صحة العمليات
- **الدوال:**
  - `layer()`: التحقق من الطبقة
  - `comp()`: التحقق من التركيب
  - `hasSelection()`: التحقق من التحديد
  - `snagOperation()`: التحقق الكامل للربط

### 3. Modules (JSX)

#### Chain.jsx (~300 سطر)
- **الغرض:** إنشاء وإدارة سلاسل الطبقات
- **الدوال الرئيسية:**
  - `createFromSelection()`: إنشاء سلسلة من التحديد
  - `create()`: إنشاء سلسلة من indices
  - `unchain()`: فك السلسلة
  - `getFullChain()`: الحصول على السلسلة الكاملة
  - `getChainInfoForSelected()`: معلومات السلسلة للعرض

#### Snag.jsx
- **الغرض:** عملية الربط الأساسية
- **الدوال:**
  - `tagHunter()`: وسم الطبقة كـ Hunter
  - `tagPrey()`: وسم الطبقة كـ Prey
  - `applyPreyControls()`: إضافة عناصر التحكم
  - `applyExpressions()`: تطبيق التعبيرات

#### Free.jsx
- **الغرض:** تحرير الطبقات من الروابط
- **الدوال:**
  - `bakeExpressions()`: تحويل التعبيرات لقيم
  - `freeLayer()`: تحرير طبقة واحدة
  - `executeSelected()`: تحرير المحدد

#### Expressions.jsx
- **الغرض:** قوالب التعبيرات
- **التعبيرات:**
  - `position()`: تعبير الموقع
  - `anchor()`: تعبير نقطة الارتكاز
  - `rotation()`: تعبير الدوران 2D
  - `rotation3D()`: تعبير الدوران 3D
  - `orientation()`: تعبير التوجه

#### Anchor.jsx
- **الغرض:** تحريك نقطة الارتكاز مع التعويض
- **الدوال:**
  - `setDirect()`: تعيين مباشر مع تعويض
  - `compensate()`: حساب التعويض
  - `setQuickAnchor()`: تعيين سريع للمحدد

#### PreyControls.jsx
- **الغرض:** التحكم بخصائص Prey
- **الدوال:**
  - `updateSnagPoint()`: تحديث نقطة الربط
  - `updatePreyAnchor()`: تحديث مرساة Prey
  - `toggleLockOrientation()`: تبديل قفل التوجه

### 4. Effects Module (JSX)

#### EffectsManager.jsx
- **الغرض:** إدارة تأثيرات After Effects
- **الدوال:**
  - `find()`: البحث عن تأثير (مع cache)
  - `has()`: التحقق من وجود تأثير
  - `addSlider()`: إضافة Slider Control
  - `addCheckbox()`: إضافة Checkbox Control
  - `cleanup()`: تنظيف جميع تأثيرات BolasPro

## 🎨 طبقة العرض (Panel)

### Controllers (JS)

#### actions.js
- `snag()`: تنفيذ الربط
- `free()`: تنفيذ التحرير
- `refreshLayers()`: تحديث قائمة الطبقات
- `toggleLock()`: تبديل القفل

#### chain-controller.js
- `updateDisplay()`: تحديث عرض السلسلة المرئي
- `selectAll()`: تحديد كل السلسلة
- `unchain()`: فك الربط
- `breakAll()`: كسر كل الروابط
- `refresh()`: تحديث العرض

#### chain-tabs.js
- `init()`: تهيئة التبويبات
- `refreshTab()`: تحديث محتوى التبويب عند التبديل

#### unified-anchor.js
- `init()`: تهيئة التحكم الموحد
- `applyAnchor()`: تطبيق المرساة حسب الوضع

### Core (JS)

#### host-service.js
- **الغرض:** جسر التواصل مع After Effects
- **الميزات:**
  - تحميل جميع وحدات JSX عند البدء
  - Promise-based API
  - معالجة الأخطاء

#### state-manager.js
- **الغرض:** إدارة حالة التطبيق
- **الميزات:**
  - حفظ/استرجاع من localStorage
  - قيم افتراضية
  - `get()`, `set()`, `save()`, `load()`

#### status-bar.js
- **الغرض:** عرض رسائل الحالة
- **الأنواع:** success, error, warning, info, ready

## 🎯 الميزات الرئيسية

### 1. نظام السلاسل (Chain System)
- ربط طبقات متعددة بطبقة رئيسية (Hunter)
- دعم الترتيب التصاعدي/التنازلي
- اختيار Hunter يدوياً أو تلقائياً
- عرض مرئي للسلسلة مع تمييز الطبقة المحددة

### 2. نظام المراسي (Anchor System)
- 9 نقاط ارتكاز قياسية
- تعويض تلقائي للموقع عند تغيير المرساة
- دعم 2D و 3D

### 3. التحكم بالـ Prey
- Snag Point: نقطة الربط على Hunter
- Prey Anchor: نقطة الارتكاز على Prey
- Lock Orientation: قفل التوجه
- Offset X/Y/Z: إزاحة إضافية
- Position/Rotation Delay: تأخير الحركة

### 4. واجهة المستخدم
- تصميم Navy Blue + Golden Yellow
- نظام تبويبات (Chain | View | Options)
- تحديث تلقائي عند التبديل بين التبويبات
- عرض مرئي للسلاسل مع ألوان مميزة
